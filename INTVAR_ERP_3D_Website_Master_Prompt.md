# INTVAR ERP — School ERP Marketing Website + 3D Hero Experience
## Master Build Prompt

Build a premium, modern marketing website for **INTVAR ERP**, a complete School Management / School ERP platform.

The goal is to make the website feel like a high-end SaaS product website rather than a traditional school software website. The visual direction must use **3D UI, cinematic motion, smooth scrolling, micro-interactions, floating dashboard panels, and an interactive hero section**.

A reference video has been provided by the user. The reference uses a cinematic 3D "floating pages / book / presentation panels" composition: multiple large rectangular panels float in 3D space, rotate around a central axis, overlap with depth, and transition smoothly as the camera/view moves. 

**Use the reference only as visual inspiration for the 3D composition and motion language. Do not copy its text, branding, images, layout, or assets. Recreate the same type of cinematic depth and page/panel movement for a School ERP product.**

# 32. Performance Requirements

3D should not destroy performance.

Implement:

- Lazy loading
- GPU-friendly transforms
- requestAnimationFrame only where required
- IntersectionObserver
- Reduced motion support
- Optimized images
- WebP/AVIF
- Code splitting
- Lazy-loaded 3D components
- Avoid excessive DOM nodes

Respect:

```css
@media (prefers-reduced-motion: reduce)
```

When reduced motion is enabled:

- Disable heavy 3D rotations
- Reduce parallax
- Use simple fade/slide animations
